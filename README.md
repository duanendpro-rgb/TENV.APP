# TENVO App — Package Complet v3

Ce dossier contient l'intégralité de l'application Tenvo prête pour GitHub et Netlify.

## 📱 Les 7 Vues Incluses :
1. **Tableau de bord Pro** (`ProDashboard.jsx`)
2. **Vue Liste Clients & Relances IA** (`ClientsView.jsx`)
3. **Fiche Client Détaillée** (`ClientProfile.jsx`)
4. **Planning & Organiseur** (`PlanningView.jsx`)
5. **Facturation & Liens de paiement** (`FacturationView.jsx`)
6. **Espace Particulier Mobile** (`MobileClientSpace.jsx`)
7. **Espace Club / Organisation** (`ClubDashboard.jsx`)

## 🚀 Déploiement GitHub & Netlify

1. Dézippez `tenvo-app-v3.zip`.
2. Sur GitHub (`github.com/duanendpro-rgb/TENVO.APP`), allez dans **Add file** -> **Upload files**.
3. Sélectionnez **tous les fichiers et dossiers** à l'intérieur du dossier dézippé (`index.html`, `package.json`, dossier `src/`, dossier `sql/`).
4. Cliquez sur **Commit changes**.
5. Netlify lancera immédiatement le build et mettra votre site en ligne !
