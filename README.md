# TENVO App — Version Mobile Optimisée

Cette version modifie la structure de l'application pour offrir une **expérience 100% Mobile (PWA / Reel)**, parfaite pour être ouverte directement depuis un smartphone.

## 📱 Changements apportés (v1.2.0)
1. **Plein écran mobile (`100dvh`)** : Le Reel interactif s'affiche désormais en plein écran sur smartphone (comme une vraie Story Instagram / TikTok) sans double ascenseur.
2. **Design Responsive ciblé :** Les composants "Intervenant" et "Pratiquant" ont été entièrement réécrits avec Tailwind pour avoir un rendu parfait sur écran vertical (téléphone).
3. **Suppression de la navigation desktop :** La barre de liens complexe en haut a été masquée lors de la vue Reel pour ne garder que l'immersion plein écran. Les boutons du Reel redirigent directement vers les vues mobiles associées.

## 🚀 Déploiement GitHub & Netlify
1. Extrais `tenvo-app-mobile-v8.zip`.
2. Glisse-dépose tout dans ton dépôt GitHub (`github.com/duanendpro-rgb/TENV.APP`).
3. Valide le commit. Ouvre ensuite l'URL Netlify **sur ton téléphone** !
